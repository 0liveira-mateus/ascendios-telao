# ascendios-telao

Página que toca um vídeo do YouTube para o telão (Projeção) do Ascendios RP.
O jogo não consegue tocar YouTube direto (Erro 153: o player precisa estar numa página https), então o telão abre esta página.

Uso: `https://0liveira-mateus.github.io/ascendios-telao/?v=ID&start=0&loop=1&vol=60`
